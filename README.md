# Експертна система туристичного агента

Навчальний проєкт з дисципліни "Проєктування експертних систем".

## Опис

Експертна система туристичного агента призначена для підбору туристичного напряму відпочинку на основі побажань користувача.

Система аналізує такі параметри:

- бюджет подорожі;
- сезон;
- тип відпочинку;
- потребу в морі;
- подорож із дітьми;
- інтерес до екскурсій;
- активний відпочинок;
- оздоровлення;
- рівень комфорту;
- готовність до далекої подорожі;
- бажання спокійного відпочинку.

## Можливі рекомендації

Система може рекомендувати такі напрями:

- Туреччина;
- Єгипет;
- Греція;
- Італія;
- Чехія;
- Карпати;
- Закарпаття;
- Трускавець;
- Болгарія;
- Чорногорія.
